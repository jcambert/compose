# Compose v0.3.0

Compose v0.3.0 adds guided Compose editing and a professional local stack administration experience while preserving the CLI-first architecture.

## Highlights

- Create, update and remove services with YAML diff preview and explicit confirmation.
- Preserve advanced Compose configuration and reject stale previews.
- Run stack-level and service-level lifecycle actions directly from the Stacks page.
- Switch workspaces reliably from the CLI or browser UI.
- Display every published local port and open it in a new browser tab.
- Use manual refresh by default or optional timed polling.
- Validate the packaged CLI on Linux and Windows.

## Upgrade

Use the normal global package update, then verify the installation with `compose --version` and `compose doctor`.

## Compatibility and security

This is a backward-compatible minor release. The local UI remains optional, binds to `127.0.0.1`, uses a short-lived access token and delegates to the same application services as the CLI.
